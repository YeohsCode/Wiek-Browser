# Wiek local evaluation framework

Repository-owned, offline-buildable framework for the same pinned 31-task dataset and canonical SDK V2 controls. Production and CI use Wiek only. Model/account runs remain explicit. Third-party notices are retained in LICENSE and the root NOTICE.

Framework version: 0.1.0-beta.1

Maintained in [Wiek Browser](https://github.com/YeohsCode/Wiek-Browser). Run the local tests with `.venv/bin/python -m pytest tests`. The application version is independent of this framework's version.
