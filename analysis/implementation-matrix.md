# Wiek Browser 能力矩阵

更新：2026-11-14。下表描述实际实现范围；“局部”不等于功能全部完成。

| 能力 | 当前范围 | 未完成或待验收 |
|---|---|---|
| 独立运行链路 | Wiek SDK/桥接/状态/错误码；全局CLI与三类Skill；运行与包检查零旧依赖 | 原始测试与许可仅作本地输入/署名保留 |
| 浏览器与SDK | 标签页、标签组和资料隔离、DOM/AX、输入、iframe/worker、文件、截图、CDP | 不等于整个浏览器引擎功能完全等价 |
| 首页与外观 | 固定网址增删改、主题、标签布局、自定义快捷键、窗口与托盘、简体中文与英文、书签搜索 | 更完整的原生设置、设备矩阵 |
| Agent 工作台 | 已接入协议、模型目录、审批、分支、附件、历史、取消与恢复 | 其他provider暂缓；原生源会话完整迁移、后台子任务 |
| 文件/Git | 范围内编辑/search/watch、Git、linked worktree checkpoint、审核式远程操作 | 更多仓库布局、真实PR账号路径 |
| 项目本地服务 | 按需发现、回环地址、单地址与批量标题识别、审核停止、微秒启动身份复核 | 全局分类、自动标题缓存、其他平台；参考运行行为未验证 |
| MCP | 传统/现代stdio与HTTP、作用域工具/资源、订阅、提示列表/预览与变更失效、OAuth/PKCE、身份审核、现代工具/资源/提示的表单和 URL 续传、审核式增量授权与公开客户端动态注册、MCP 2025-11-25 会话式 URL 审核 | 托管客户端身份和需凭据的动态注册、sampling/roots |
| 资料迁移 | 同类浏览器多资料夹导入、v4 加密档案及每个标签页最多 64 条前进和后退记录、显式localStorage/sessionStorage、有界IndexedDB（含 Map、Set、RegExp、自增键、共享与循环引用、稀疏数组、固定缓冲区视图和 Blob/File） | 其余复杂类型 IndexedDB、跨浏览器批量混合来源、跨来源或嵌入页面的会话状态、OS 绑定密文迁移 |
| 自动化 | 时区/DST、执行模式、后台作业、忙碌延期、记忆/结果、停止判定与恢复 | 物理sleep/login、后台项撤销；9 种安装和更新布局与链接身份保护已验收 |
| 桌面/录制 | 显式采集、被动工具栏、指定应用录制、安全输入边界与孤儿自停、应用包面板验收 | 最终包正向、实际撤权、多屏、更多应用 |
| 语音/翻译 | 本地转写、词典/历史；中英/中西四例源码及打包服务 | 不代表一般质量；模型另行安装 |
| 本地记忆 | 明确来源的UTF-8字面索引与删除/隔离 | 语义检索、全盘采集和自动注入未实现 |
| 交付/评估 | macOS ARM64包、固定输入CI、共享V2框架、本地双侧smoke | 31任务线上评估、签名/公证与正式发布 |

本轮功能研究链路见[本地服务设计](local-services-design.md)及[身份摘要](../reports/local-services-research.json)。原始许可与历史调查保持原始记录；公开说明使用当前产品名称。
