# 浏览器操作经验设计与使用

目标：让 Wiek 在后续相同任务中参考经过审核的操作证据，减少重复错误；对检查过的步骤进行有条件的重放。历史成功不能证明当前页面仍然正确。界面中的名称统一为「浏览器操作经验」「建议」「结果检查」「步骤重放」。

## 状态与信任边界

宿主保存任务运行 ID、单次操作 ID、执行状态及独立的页面结果检查。命令正常返回只表示执行完成；只有宿主读取当前页面并满足显式条件，任务才标为结果已验证。失败后恢复并通过结果检查，可以产生待审核的建议。它不会自动成为可执行流程。

安全作用域由宿主从受控标签组取得：浏览器资料、项目、确切的网站 origin。普通独立任务的项目为 null；MCP 项目来自既有线程绑定。调用者不能提交或覆盖这些字段。建议还按完全相同的任务名召回，不做跨站或模糊语义扩散。不同页面的运行 ID 和操作 ID 不能互换。

默认关闭。在「设置 → 浏览器操作经验」开启后，可以选择仅提供已审核建议，或额外允许经过检查的步骤重放。脚本和 MCP 无权开启、审核、编辑、回滚、删除经验。设置、审核与编辑使用整个存储的 revision 和候选 version 检测竞争；编辑或恢复历史版本都会产生待审核的新版本，旧版保留以供追溯。错误的重放会撤回当前版本的启用状态。

本地 JSON 使用单写者锁、原子替换、0600 文件和有界容量。重启后的未完成操作被标为不确定，不自动恢复执行；若中断的是重放流程，对应建议会撤回启用状态，等待重新审核。记录不保存输入值、Cookie、凭据、页面全文、URL 查询参数或片段。显式提交的检查文本、选择器和建议正文会被保存；它们是用户/调用者选择提供的数据。当前作用域的「删除记录与建议」会一起清除证据、版本和建议，不能靠回滚找回。关闭只停止使用，不自动删除数据。

## 实际执行入口

SDK `page.experience(action, payload)` 与 MCP `browser.experience` 调用同一个宿主服务。SDK 的元素操作、导航和原始鼠标/键盘操作在已有操作边界自动记录名称和结果；仅自动保留受限的简单 CSS ID（如 `#apply`），不保存含文本/属性值的选择器、输入值或错误正文。建议带有对应的失败与恢复操作证据，下一轮可据此选择目标，而不是只得到一句泛化提醒。未启用或没有当前记录任务时，观察为空，不阻塞正常自动化。已开始的任务可跨 CLI 进程继续记录。切换网站时结束旧网站的自动记录，不把旧建议带到新网站，也不会阻塞正常导航；达到事件容量后停止追加自动记录。`snapshot()` 在有已审核的同任务建议时附加标明为历史数据的 JSON；原有未启用时的快照格式保持不变。

原始 JavaScript、CDP、截图坐标只适合诊断，不能导入为可自动执行的重放步骤。重放目前支持经过检查的点击和同源路径导航。填写、上传、支付、系统权限等不纳入自动复用；已有的浏览器操作 API 仍可在正常任务中使用。这是重放策略的限制，不是浏览器功能的削减。

示例：先在设置开启，再在已打开的 HTTP(S) 页面开始记录。

```js
await page.experience('start', {task: '应用筛选'});
try { await page.click('#obsolete', {timeout: 500}); } catch {}
await page.click('#apply');
const checks = [{kind: 'element', selector: '#result', attribute: 'text', equals: '已完成'}];
console.log(await page.experience('verify', {checks}));
// 先前失败/不确定，之后执行并验证成功：自动形成待审核建议。
// 也可主动提出带说明的建议；仍然需要浏览器界面审核。
console.log(await page.experience('propose', {note: '先检查应用按钮的当前文字，再操作并检查结果。'}));
```

`verify` 必须读取当前唯一匹配元素的非输入文字、`aria-label`、`data-state`、`data-status`，或校验当前 URL 路径。不会执行调用者提供的检查脚本。支持的条件是刻意有限的，不能证明真实网站后台状态；任务作者应选择能代表业务结果的标记。

## 经过检查的步骤与部分步骤

使用 `perform` 执行具有前后检查的结构化步骤，才能形成可重放证据：

```js
await page.experience('perform', {recipe: {
  type: 'click', selector: '#apply', tag: 'button', text: '应用',
  before: [{kind: 'element', selector: '#result', equals: '待处理'}],
  after: [{kind: 'element', selector: '#result', equals: '已完成'}]
}});
await page.experience('verify', {checks});
const suggestion = await page.experience('propose', {note: '使用应用按钮并确认完成标记。'});
// 在设置审核 suggestion。后续相同任务新一轮运行：
await page.experience('start', {task: '应用筛选'});
console.log(await page.experience('replay', {id: suggestion.id, version: suggestion.version}));
```

每次点击重新解析唯一可见目标，校验标签、文字和可选角色，再按当前几何位置发送输入。移动按钮不依赖旧坐标；ID、文字、角色或前置条件变化会暂停。执行前先把不确定状态持久化。执行后的业务检查失败时不再次发送输入，返回 `suspended`、`requiresObservation` 和 `mayHaveDispatched`。此时应先观察，必要时交给用户。整个过程继续检查既有控制权，不绕开用户接管或系统提示。

`propose` 可提供同一任务内连续且顺序不变的 `eventIds`，提取一组部分步骤。它沿用最后一步的结果检查，并明确返回 `completeWorkflow: false`，不能当作整个任务完成。经历失败、原始操作回退或只记录到部分步骤的任务，也不会标成完整流程。候选保存相同步骤在已验证运行中的观察次数，供审核时判断是否值得复用；次数不等于成功率，也不替代结果检查。

## 外部系统兼容

外部系统通过已有 SDK 或 MCP 提交 `{format: 1, source, note, steps?}` 给 `propose`。来源是显示用的自报标签，不是可信签名。步骤必须与当前运行的宿主检查记录一致；传来的任意脚本、未知字段、未验证步骤、跨作用域证据和未知格式都会拒绝。导入结果始终待审核。没有要求引入新的 Agent provider、向量数据库、云服务或模型供应商。

兼容借鉴的范围：页面操作缓存中的定位信息适合做候选，但要补业务结果校验；持久规则库适合保存修正与版本，但不能直接信任 Agent 声称的成功；后台优化机制适合提出草稿，但不能自行批准执行；版本化工作流适合恢复已验证步骤，但必须保留前后检查及失败暂停。实现不依赖任何第三方系统宣称的成功率，也不复制它们的实现代码。

## 与已研究框架的兼容取舍

| 系统 | 参考的机制 | Wiek 的接入与限制 |
|---|---|---|
| Webcmd | 从操作中整理可复用技巧、版本记录 | 使用带证据的本地草稿；不把日期或文件存在当成验证，也不依赖外部 Git 存储 |
| Midscene / Stagehand | 定位及步骤缓存、失败后的重新观察 | 保存结构化目标和前后检查；同文字但效果变化也要检查结果，不能只看定位仍可点击 |
| Browser Use | 任务结果和历史反馈 | 区分执行结果与宿主检查；不用 Agent 自报成功决定经验可执行性 |
| Hermes | 持久规则、人工修正 | 通过同一审核入口存版本；规则正文不自动升级为权限或执行代码 |
| OpenClaw | 从执行记录生成优化草稿 | 先产生待审核建议；不引入自动写入并启用规则的后台循环 |
| Skyvern | 带版本的工作流和失败恢复 | 复用经过检查的完整或部分步骤；旧版本、回退和不确定输入分别记录 |

这些是接口与设计取舍，不声称与这些系统的数据文件、私有协议或任意脚本直接兼容。外部系统可以通过版本 1 的建议格式和 MCP 适配，不需要它们的运行依赖。比较针对已检查机制，不把 README 中的宣传当作效果证据。

## 验收与边界

测试分为存储/作用域/审核回归、真实 Chromium 页面操作、SDK/MCP 普通入口及中英文界面。比较无经验、仅建议和步骤重放三种方式，记录实际页面结果、重复错误、点击副作用和模型调用。确定性测试不调用模型，模型调用数均为 0，因此不能用这组测试宣称减少了多少模型成本或真实网站成功率。

必须覆盖两轮复用、定位变化、同标签但业务行为变化、错误 ID、部分回退、不确定提交、用户接管、竞争写入、重启、版本和删除。已有原始 SDK 及浏览器测试输入保持不变。真实账号、多站点长期学习和线上模型收益仍需要独立数据，不能由本地夹具推断。
