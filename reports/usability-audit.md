# 术语、自动化阻塞与功能必要性审计

日期为 2026-11-11。本报告核对当前源码和安装版指南，并在独立临时数据目录运行真实 Electron、CLI 与 SDK。测试只访问回环网页，模型请求和真实账号操作均为零。

## 结论与已做修正

“空间恢复”混用了三个概念，分别为启动时重新打开标签页、重新打开已关闭标签组、继续自动化任务。此前解释将这三个概念混在了一起，现按[术语表](../docs/terminology.md)区分。

当前界面没有名为“空间恢复规则”的设置，也没有恢复确认对话框阻塞所有 CLI 请求。`wiek-browser skill` 中的一目标一任务、禁止新建任务恢复、失败后必须询问用户等说明，会使遵循说明的测试 Agent 主动停止。SDK 对任务结束的错误提示也要求重新询问，忽略了会话里已提供的授权。已改为状态明确的恢复步骤、独立测试可创建独立任务、已有授权可继续目标页面。

## 已复现的触发条件

| 操作 | 实际结果 | 阻塞原因 | 处理方式 |
|---|---|---|---|
| 浏览器持续运行，下一次脚本复用 ID 与 p1 | 页面可读，未提交输入仍在 | 此路径正常 | 继续复用任务和有效标识 |
| 浏览器重启，直接用原 p1 | `page label not found: p1` | Chromium target 已变化。SDK 按浏览器实例隔离页面标识，新打开的页归为来源未知 | 在已授权且可控的任务中重新列举标签页，按 URL/标题选页并 adopt，或新建独立测试任务 |
| `finish({keep:[...]})` 后用同名任务开始新测试 | `WIEK_TASK_SPACE_NAME_IN_USE` | 保留的标签组归用户，原任务及页面标识已结束 | 新测试用唯一任务名；明确继续已有页面时按授权 claim |
| 对已结束任务调用 takeOver | `WIEK_TASK_SPACE_INACTIVE`，CLI 退出 1 | takeOver 用于临时移交，不能重新分配已结束任务 | 已授权时 claim，或创建新测试任务 |
| handOff 后尝试继续读页 | `WIEK_TASK_SPACE_USER_IN_CONTROL`，CLI 退出 1 | 当前控制权交给用户 | 用户交回后 takeOver 并重新列举页面 |
| 重启后 adopt 原网址的页面 | 页面可正常操作，原输入为空 | 重开只保存 URL，输入框的内存状态未保存 | 测试重新设置数据 |
| 已完成的同名组仍保留，新测试使用其他名称 | 新任务正常导航、读标题并完成，原页面保留 | 已有标签组不会阻塞整个浏览器 | 不把名称冲突扩大成整个任务的强制停机 |

初始复现为一个真实端到端用例、17 项行为检查全部通过，日志见 [terminology-recovery-initial.log](terminology-recovery-initial.log)。这是对原问题触发条件的复现通过。修改后的最终完整源码回归为608/608，原始SDK532/532，真实面板专项12/12，导入标题夹具修正后相关8/8。实际0.24应用包也通过相同17项恢复检查。见[完整源码](v024-source-tests-final.log)、[SDK](terminology-sdk-regression.log)、[面板](terminology-focused-tests.log)、[修正复测](terminology-recovery-final.log)与[实际包](terminology-packaged-recovery.log)。

全局命令和三种Agent技能入口已更新到验证过的0.24目录包，[安装记录](terminology-installed-entrypoints.json)和[实际输出指南](terminology-installed-guide.md)可核对。界面文案来自该新应用包，正在运行的旧应用窗口须在结束后从新包启动才能显示新文案。

对应代码为 `packages/sdk/skill-body/SKILL.md`、`packages/sdk/src/helpers.ts`、`packages/sdk/src/wiek-errors.ts`、`packages/sdk/src/page-ledger.ts`、`app/main.cjs` 和 `cli/wiek-browser.mjs`。启动恢复在 RPC 发布之前重建标签页，但没有等待远端网页加载完成。本次未观察到启动等待超时。

另一个诊断障碍位于 `packages/sdk/src/output-sink.ts`。控制权错误会设置本次调用的 hard-stop 标记，普通 `console`/`cliLog` 日志随后被丢弃，只留下控制提示。如果脚本捕获了异常，进程还可能退出 0。532 项原始 SDK 回归中的输出测试验证了此行为。因此外层测试程序仅检查退出码可能误判成功，Agent 又只看到停止提示。此项作为输出契约改进建议列入清单，当前控制权边界仍按稳定错误码处理。

目前未获得用户那次失败调用的命令和日志，不能将其中某个触发条件认定为那次事件的唯一根因。以上条件均有本机实际复现支持。

## 0.25 跟进

`wiek-browser nodejs` 将脚本日志保留在 stdout，向 stderr 输出 `[wiek-browser:error]` JSON 记录，并在控制错误被脚本捕获后仍返回退出码 1。现有 SDK 嵌入入口保留原输出契约。

`wiek-browser start --no-restore` 启动空白标签页，保存的标签组延后到下次正常启动重开。浏览器配置、书签、历史、下载与权限均从原数据读取。

## 功能必要性清单

以下为对当前已有能力和待办的产品判断。重命名、纠正操作指引已实施。功能合并、隐藏和移除列为建议，未在本次擅自删除用户数据或既有能力。

| 功能或设计 | 判断 | 建议与理由 |
|---|---|---|
| 一个目标只能有一个 TaskSpace，失败必须询问才能新建 | 多余限制 | 已移除绝对限制。独立测试需要隔离的任务和数据 |
| 控制错误丢弃整次脚本普通日志，捕获后仍可能退出 0 | 0.25 已修正命令行入口 | 命令行返回非零并保留日志和结构化错误。直接嵌入 SDK 时沿用既有契约 |
| 任务结束一律要求再次询问授权 | 多余限制 | 已改为先使用当前会话已有授权。明确用户接管和网站权限交互仍需按其状态交接 |
| 把所有继续使用行为都叫“空间恢复” | 误导命名 | 已拆成重新打开标签页、重新打开标签组、继续任务 |
| Agent working / Agent running 表示标签组归属 | 不符合事实 | 已改为 Agent has control。有控制权并不证明正在执行 |
| 重启时重新打开上次标签页 | 常规浏览器能力 | 保留。当前没有普通用户可选的启动页设置，后续可补“新标签页 / 上次标签页”选项 |
| 最近关闭的标签组历史 | 有用的撤销入口 | 保留最近 30 条，明确叫重新打开。无需再包装成单独恢复系统 |
| 自动化页面标识、实例隔离 | 必要 | 保留。防止旧句柄误操作重启后的其他页。指南应说明生命周期 |
| 用户/Agent 控制权交接 | 必要 | 保留。修正错误提示造成的重复确认，不自动抢回用户正在操作的页面 |
| 所有辅助功能常驻主侧栏 | 入口过多 | 建议将语音、翻译、操作记录、外部工具和后台任务集中到工具菜单，主界面优先浏览、任务、书签与下载 |
| 浏览器设置与 Preferences 分两层 | 重复入口 | 建议合并到设置页，保留外观、快捷键、数据和高级选项分区 |
| Library 与网页书签都能存网页引用 | 使用目的重叠 | 建议书签负责网址，已保存内容负责文本和截图，两个入口相互说明 |
| Collections + Groups + Tags 三套组织 | 复杂度偏高 | 建议默认文件夹加标签，子分组放高级编辑。先核对现有数据迁移 |
| Indexed memory，被称为记忆却做字面搜索 | 名称夸大，另有存储入口 | 已改为已保存文本搜索。建议以后并入已保存内容的搜索 |
| 网页操作记录与桌面应用操作记录 | 对专门调查有用，普通浏览低频 | 标明事件和截图时间线。建议工具菜单按需打开，保持默认关闭 |
| 桌面截图编辑与网页截图编辑 | 编辑能力重复 | 建议共用一个截图编辑入口，保留不同采集来源 |
| 定时任务与 macOS 后台运行两套开关及审核 | 条件合理，流程复杂 | 建议在每个任务里解释“浏览器开启时 / 关闭后也运行”，系统后台安装集中一次。实际执行和安装权限仍需准确表达 |
| 自动文件备份、手动备份和 Git stash | 目的部分重叠 | 修改项目文件的 Agent 需要可追溯备份。建议同页呈现，自动备份按项目自愿启用，Git stash 保留其原生语义 |
| 加密浏览器备份与多类网站存储导入 | 高级迁移能力 | 有必要但低频，放“数据导入导出”的高级选项，不作为浏览或自动化前置步骤 |
| 离线翻译和语音模型 | 可选辅助能力 | 按需安装与启用，避免普通浏览需要准备模型 |
| 本地服务端口发现与页面标题探测 | 开发场景有用 | 项目工具里保留。自动分类与自动探测标题没有普通浏览前置价值，可继续延后 |
| `--no-restore` 启动参数 | 0.25 已收窄作用范围 | 跳过重开标签页，保留浏览器资料与已有标签组 |
| 31 项线上模型评估、签名/公证、多屏和系统会话验收 | 验收工作 | 继续作为交付待办，不能归入“画蛇添足的功能” |

## 验证边界

本次主要修正面向用户的用词和操作指引。公开方法、数据结构及控制权判定兼容原有调用。没有自动将旧页面标识绑定到重启后的新页。

上轮 0.24 的完整源码回归曾分别出现文件监听等待和远程 Git 子进程超时，失败日志仍保留。这些失败发生在文件服务测试中，和本次自动化标签页的恢复错误无直接证据关联。完整 0.24 发行验收继续保留在计划中，不能以本次专项通过替代。
