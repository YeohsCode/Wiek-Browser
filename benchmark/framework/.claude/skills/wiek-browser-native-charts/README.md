# Wiek Browser-Native Charts

A reusable skill for generating self-contained HTML/CSS benchmark charts in a browser-native editorial style.

## Style name

**Browser-Native Editorial Benchmark**
中文可称：**浏览器原生编辑式基准图表**。

## Files

- `SKILL.md` — complete generation rules and validation checklist.
- `templates/browser-native-dual-card.html` — two-metric comparison template.
- `templates/browser-native-hybrid.html` — overall + subgroup comparison template.
- `examples/interaction-turns.html` — finished example using the latest interaction-turn data.

## Installation

Copy the entire `wiek-browser-native-charts` folder into the skills directory used by your agent environment. Keep the folder structure intact so the skill can access its templates.
